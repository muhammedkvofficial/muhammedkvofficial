# Hi, I'm Muhammed KV

**Digital Marketer & Web Developer based in Calicut, Kerala**

I handle both halves of an online presence: the website that gets built, and the marketing that gets it found. Most businesses buy those separately and pay for it later, because a site built without search in mind is expensive to fix, and ads pointed at a slow page waste budget.

- **SEO**: technical audits, on-page optimization, content strategy, and local search
- **Paid advertising**: Meta Ads and Google Ads campaigns focused on measurable return
- **E-commerce development**: fast, conversion-focused online stores
- **Web development**: responsive websites built with HTML, CSS, and JavaScript
